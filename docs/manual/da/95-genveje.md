# Tastaturgenveje

Genvejene står også i værktøjstippet, når du holder musen over en knap i båndet, og i menuerne.

## Overalt

| Handling | Genvej |
|---|---|
| Maskér | ⌘1 |
| Demaskér | ⌘2 |
| Noter | ⌘3 |
| Sager | ⌘4 |
| Ordbog | ⌘5 |
| Indstillinger | ⌘, |
| Større tekst | ⌘+ (eller ⌘=) |
| Mindre tekst | ⌘− |
| Normal tekststørrelse | ⌘0 |
| Luk vindue | ⌘W |
| Afslut Grimnir | ⌘Q |

⌘1–⌘5 virker ikke, mens en dialog er åben, eller Grimnir er låst. Tekststørrelsen kan altid ændres.

## Maskér og Demaskér

| Handling | Genvej |
|---|---|
| Indsæt tekst eller svar | ⌘V |
| Åbn fil | ⌘O |
| Gem (**Gem maskeret fil** eller **Gem som fil**) | ⌘S |
| **Maskér** (analyserer først, hvis teksten ikke er analyseret) eller **Demaskér** | ⌘↵ |
| **Kopiér maskeret tekst** eller **Kopiér resultat** | ⇧⌘C |
| **Maskér markering** | ⇧⌘M |
| **Fortryd** og **Gentag** (dine valg i Maskér) | ⌘Z og ⇧⌘Z |
| **Næste advarsel** (Demaskér) | ⌘G |

Står markøren i et tekstfelt, fx **Erstatning** eller søgefeltet, fortryder ⌘Z i feltet.

## Andre steder

| Hvor | Tast | Gør |
|---|---|---|
| Låseskærmen | Enter | **Lås op** |
| Noter | ⌘↵ | Gemmer noten |
| Noter, under en rettelse | Esc | Annullerer rettelsen |
| Sager | Enter eller dobbeltklik | Viser sagens indhold |
| Sagens indhold | Esc | Tilbage til sagerne |
| Prøv ordbogen på en tekst | ⌘↵ | **Prøv** |
| Guiden | Enter i et felt | **Tilføj** |
| Guiden | Esc | **Spring over** |
| En dialog | Esc | Lukker dialogen |
