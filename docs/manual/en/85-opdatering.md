# Updating

Grimnir does not update itself and does not check for new versions. It has no network code, so it cannot ask anyone whether a new version exists. You look for yourself under the releases on GitHub (`github.com/wi24rd-com/grimnir`, under Releases).

## How to update

1. Quit Grimnir (⌘Q). If the temporary case has values, save or discard it when Grimnir asks.
2. Download the new zip file from the release on GitHub, and open it.
3. Drag **Grimnir** to Applications, and choose to replace the old one.
4. Check what you downloaded, if you like, with the commands in [Installation](20-installation.md).
5. Open Grimnir.

## Your data stays

Your cases, your dictionary and the settings are in the data folder `~/Library/Application Support/com.wi24rd.grimnir/`, and the keys are in the keychain. They are outside the program and stay when you replace it. See [Data](70-data.md).

A case from a newer version of Grimnir cannot be opened by an older version. It then shows in **Cases** as **Cannot be opened** with the reason **the file is from a newer version of Grimnir (format …)**.

## The version you have

The version is at the bottom right of the window (**Version** and **Core**) and in **About Grimnir**.
