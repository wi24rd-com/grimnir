# Keyboard shortcuts

The shortcuts are also in the tooltip when you hold the mouse over a button in the command bar, and in the menus.

## Everywhere

| Action | Shortcut |
|---|---|
| Mask | ⌘1 |
| Unmask | ⌘2 |
| Notes | ⌘3 |
| Cases | ⌘4 |
| Dictionary | ⌘5 |
| Settings | ⌘, |
| Larger Text | ⌘+ (or ⌘=) |
| Smaller Text | ⌘− |
| Normal Text Size | ⌘0 |
| Close Window | ⌘W |
| Quit Grimnir | ⌘Q |

⌘1–⌘5 do not work while a dialog is open or Grimnir is locked. The text size can always be changed.

## Mask and Unmask

| Action | Shortcut |
|---|---|
| Paste text or reply | ⌘V |
| Open file | ⌘O |
| Save (**Save masked file** or **Save as file**) | ⌘S |
| **Mask** (analyses first if the text has not been analysed) or **Unmask** | ⌘↵ |
| **Copy masked text** or **Copy result** | ⇧⌘C |
| **Mask selection** | ⇧⌘M |
| **Undo** and **Redo** (your choices in Mask) | ⌘Z and ⇧⌘Z |
| **Next warning** (Unmask) | ⌘G |

If the cursor is in a text field, e.g. **Replacement** or the search field, ⌘Z undoes in the field.

## Other places

| Where | Key | Does |
|---|---|---|
| The lock screen | Enter | **Unlock** |
| Notes | ⌘↵ | Saves the note |
| Notes, while editing | Esc | Cancels the edit |
| Cases | Enter or double-click | Shows the case contents |
| The case contents | Esc | Back to the cases |
| Try the dictionary on a text | ⌘↵ | **Try** |
| The guide | Enter in a field | **Add** |
| The guide | Esc | **Skip** |
| A dialog | Esc | Closes the dialog |
