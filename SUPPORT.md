# Support

Wi24rd Grimnir is an open source project maintained by one person in spare time. There is no support service and no guaranteed answer.

- **How the app works:** see [README.md](README.md) (Danish: [README.da.md](README.da.md)).
- **A bug or a wish:** open an issue with the templates. Use made-up values only: no passwords, keys, case files or logs with real data.
- **A security vulnerability:** see [SECURITY.md](SECURITY.md). Do not open a public issue.
- **Changing the code:** see [CONTRIBUTING.md](CONTRIBUTING.md).
