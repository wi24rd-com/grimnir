En statuschip siger én ting om én række med symbol, ord og farve, så betydningen aldrig hviler på farven alene.

| Variant | Symbol | Flade / tekst | Bruges til |
|---|---|---|---|
| OK | ✓ | `accent-soft` / `accent` | sikker, færdig, i orden |
| Advarsel | ! | `warn-soft` / `warn` | sandsynlig, udløber snart, kræver et blik |
| Fejl | ? eller ! | `danger-soft` / `danger` | tjek selv, ukendt, fejlet |
| Oplysning | i | `info-soft` / `info` | neutral besked |
| Ingen | – | `surface-raised` / `text-muted` | ikke relevant, ikke brugt |

Højde 22 px, `radius-pill`, tekst i `small` med vægt 600. Én til to ord. Forbrugeren leverer variant og ord; symbolet følger varianten.
